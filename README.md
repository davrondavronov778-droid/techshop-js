# Практическая работа № 1 • TechShop
## Ответы на контрольные вопросы

**1. Для чего нужен JavaScript?**
JavaScript нужен для того, чтобы сделать веб-страницу интерактивной: реагировать на действия пользователя (клики, ввод текста), динамически изменять содержимое и стили элементов без перезагрузки страницы, а также работать с данными.

**2. Как подключить внешний файл script.js?**
Внешний файл подключается с помощью тега `<script src="script.js"></script>`, который обычно размещают перед закрывающим тегом `</body>` в конце HTML-документа, чтобы к моменту запуска скрипта все элементы страницы уже загрузились.

**3. Что такое DOM?**
DOM (Document Object Model — объектная модель документа) — это представление HTML-страницы в виде дерева объектов, к элементам которого JavaScript может обращаться, чтобы читать, изменять, добавлять или удалять их содержимое и свойства.

**4. Для чего нужен querySelector()?**
Метод `document.querySelector()` находит и возвращает первый элемент на HTML-странице, который соответствует указанному CSS-селектору (например, по `id`, классу или названию тега).

**5. Что такое событие click?**
Событие `click` — это сигнал браузера о том, что пользователь нажал и отпустил левую кнопку мыши (или коснулся экрана) на определённом элементе страницы (например, на кнопке).

**6. Что делает addEventListener()?**
Метод `addEventListener()` привязывает к выбранному HTML-элементу функцию-обработчик, которая автоматически выполнится в тот момент, когда с этим элементом произойдёт указанное событие (например, `click`).

**7. Зачем используется textContent?**
Свойство `textContent` используется для чтения или безопасной замены обычного текста внутри выбранного HTML-элемента (без обработки HTML-тегов).

**8. Почему сообщение появляется только после нажатия?**
Потому что код изменения текста помещён внутрь функции-обработчика события `click` в методе `addEventListener()`. Браузер не запускает эту функцию при загрузке страницы, а ждёт, пока пользователь нажмёт на кнопку.

**9. Чем отличаются селекторы #buy и .product?**
Символ `#` (`#buy`) используется для поиска уникального элемента по его атрибуту `id`, а точка `.` (`.product`) — для поиска элементов по атрибуту `class`, который может повторяться у нескольких элементов на странице.

**10. Что произойдёт, если указать несуществующий id?**
Метод `document.querySelector()` вернёт значение `null` (пустоту). При попытке сразу вызвать для него `.addEventListener()` или изменить `.textContent` в консоли браузера появится ошибка `TypeError: Cannot read properties of null` (невозможно прочитать свойства `null`), и дальнейшее выполнение скрипта на этом месте прервётся.
